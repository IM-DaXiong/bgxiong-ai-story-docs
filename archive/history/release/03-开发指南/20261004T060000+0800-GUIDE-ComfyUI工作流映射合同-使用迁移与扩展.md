# GUIDE · ComfyUI 工作流映射合同：使用、迁移与扩展

**日期**：2026-10-04 · **权威**：[SPEC](../04-开发规范/20261003-SPEC-ComfyUI工作流映射合同.md) · 「PLAN」（开源版未收录该内部文档或源码路径） · 「执行台账」（开源版未收录该内部文档或源码路径）

## 1. 用户流程

1. **发现**：工作流库可从本地导入，也可列举 ComfyUI 服务端保存项（`/userdata` 的 `workflows/`，带 `comfy-user` 头）。服务端卡片会显示“已导入为「名称」/ComfyUI 中已更新”，并提供“重新导入并映射”。
2. **分析**：`analyze_comfyui_workflow_mapping_cmd` 按所选输出节点的祖先拓扑生成 `MappingContractV1`：正负提示词、seed、生图尺寸、固定写入、素材槽（具名首尾帧 / indexed autogrow / flat LoadImage），视频还会生成 timing / resolution 子合同。
3. **确认**：拓扑明确就自动绑定；有歧义（多个候选目标）或节点定义不全时弹出映射确认层，由用户选定。确认本身不触发生成。
4. **冻结与提交**：合同按稳定身份（instanceId / userScope / sourceKind / 规范路径）存入 `MappingRepository`。提交时 `resolve_submission_contract` 复用合同，没有合同就惰性冻结；源或相关节点定义变了就显式报 stale，不会悄悄改用旧逻辑。最终统一由 `prepare_contract_submission` 写入，这是唯一写入路径。

## 2. 显式错误（不猜测、不回落）

| 错误码 | 含义 | 用户处理 |
| --- | --- | --- |
| `workflowMappingNeedsConfirmation` | 存在歧义绑定 | 在映射确认层选定 |
| `workflowMappingStale` | 源图或相关节点定义已变化 | 重新导入并映射 |
| `workflowMappingCorrupt` | 本地合同文件损坏（原文件不覆盖） | 重新映射 |
| `workflowMappingOutputMissing` | 无可用输出节点 | 检查工作流输出 |
| `workflowWidgetLayoutUnknown` | 未知第三方节点带位置 `widgets_values` | 改用 API 格式导出，或在 `node_registry` 登记该节点 |
| `workflowLegacyPlaceholderUnsupported` | 含 `{{PROMPT}}` 等旧占位符 | 去掉占位符，按普通工作流重新导入 |
| `workflowRemoteSourceForbidden` / `workflowRemoteSourceUnsupported` | 服务端拒绝访问 / 旧版服务不支持 `/userdata` | 检查权限或升级 ComfyUI |

## 3. 迁移说明

- 旧 `{{PROMPT}}` 字符串模板不再是提交路径（S32），内置模板都已改为无占位符的 API 图。用户自定义的占位符模板要去掉占位符后重新导入，提示词、seed 等由合同自动识别。
- 旧 caps/source 数据不做批量迁移（D3/D6）：首次提交时惰性冻结合同；拿不准的情况会走确认流程，不会运行时回落旧注入器。
- 超分（SeedVR2/FlashVSR）和视频精修使用各自固定的认证图，不受用户工作流映射影响（D10）。

## 4. 扩展：新增工作流或特殊节点

- **只用已支持节点的新工作流**：不需要改源码，导入后自动映射（S35 证据：`video_flashvsr_hd_upscale.json`）。
- **新增特殊节点**：只在 `src-tauri/crates/bgx-comfy-workflow/src/node_registry/` 登记节点角色和 widget 顺序（`WidgetLayout::Ordered / NoApiInputs / TextGenerateDynamicCombo`，`control_after_generate` 用 `WidgetSlot::UiOnly` 占位），顺序以节点源码 `INPUT_TYPES` 为准，并在 `tests/fixtures/` 增加夹具；规则变化需提升 `RULE_REGISTRY_VERSION`。禁止按节点 ID 顺序或字段名猜测。
- 素材、时长、分辨率规则只能复用宿主 `asset_adapt` / `duration_slots` / `resolution_slots`（D1），不得另写识别器。

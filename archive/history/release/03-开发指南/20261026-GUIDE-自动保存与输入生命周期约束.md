# 自动保存与输入生命周期约束

> **开源整理版**（2026-11-12）：已去除或改写私有路径、未公开端点、凭证示例，以及登录 / 认证 / 付费相关实现细节。若某节全部属于上述范围，将改为一句能力边界说明。


2026-11-11 用户裁决：生图/视频工作台暂停编辑时的定时写回和失焦保存，保留关闭、手动保存与提交前保存，避免未完成提示词产生历史版本。本次是保存时机调整，不是用关闭自动保存掩盖输入连续性故障；其它编辑器仍遵守下文。实现与定向验收见「FIX」（开源版未收录该内部文档或源码路径）。

日期：2026-10-26。适用全仓输入框、富文本、图片/视频/音频工作台与详情表单。

## INV-INPUT-CONTINUITY

1. 自动保存、保存回执、偏好落盘与无关任务刷新必须在后台完成。同一实体同一字段持续编辑时，不能因此设置 `disabled`、`readOnly`、`contentEditable=false`，或以新 `key` / 条件渲染卸载编辑器。
2. 保留 DOM 身份、焦点、caret/选区、编辑区滚动位置与中文 composition 缓冲。不得用强制 focus、重置光标、额外延时、取消自动保存或吞错代替根因修复。
3. 生成、参考图重排等真实互斥按所属节点及操作维护独立锁。禁止将整个工作区 `writing`、设置 `saving` 或其他入口的 busy 当成当前提示词编辑锁；后台提示词保存不是参考图重排。
4. 保存请求冻结实体、字段和提交稿。旧回执只确认该提交版本，不覆盖后来输入、不清除后来 dirty，不把 A 实体回包应用到 B 实体。失败保留最新编辑内容并显式呈现重试入口。
5. 离开保存只在真实实体切换/关闭/卸载触发。同实体 rerender 只更新回调引用，不能因依赖函数或对象身份变化执行 cleanup 保存。优先复用 `domain/content-autosave` 的实体隔离生命周期。
6. 同实体的普通保存回执不重新读取正文。只有真实实体/字段切换、用户选择历史或已明确受理的外部写入才按既有合同水合；外部写入仍须尊重版本归属及输入事务。

## 最低行为验收

扩已有用例，使用真实宿主保存生命周期与延迟回执，检查后台保存进行中仍可输入、同一 DOM/焦点/选区保持、保存后后来输入不被覆盖。图片和视频共享宿主均需覆盖；真实参考图重排仍保持其合法操作锁，完成/失败后释放。中文 composition、实体切换和迟到回执沿既有编辑器/自动保存回归维护。

测试需区分真实宿主接线与模拟的工作台展示边界；不能将仅编辑器通过写成完整 GUI 已验，不为同一机制另建一套测试脚本或状态系统。

## 显式 AI 写入的局部互斥（2026-11-05）

显式 AI 写入可复用 `OperationLoadingBoundary`，按实体归属传入真实任务 busy，保持原编辑 DOM 并阻止编辑和保存；保留任务进度入口。剧集两个宿主使用 `useChapterCreationWrite`，受理立即锁定，经现有 run 生命周期的完成/失败/取消解除。不得把后台自动保存状态接到该边界。当前落地及未验范围见 「FIX」（开源版未收录该内部文档或源码路径）。

## 画布空写与视口会话（2026-11-10）

片段和自由画布工作台配置以 JSON 内容判断变更，忽略对象字段顺序及序列化空白，保留数组顺序与字段删除语义；相同内容不提交写入。视口保存会话按工作区身份持有，回读新对象不触发 dispose/flush，真正离开仍提交未完成的有效操作到原宿主。真实任务回执或外部写入仍按原 CAS 与版本合同处理。实现和验证边界见「FIX」（开源版未收录该内部文档或源码路径）。

**文档日期**：2026-05-09  
**文档性质**：**权威规范** — 本文档是全仓语义命名的唯一真相来源。  
**合并来源**：`20260508-GUIDE-全仓语义命名收敛与落地手册.md`、`20260509-PLAN-storyId-chapterNodeId全栈命名收敛.md`、`20260509-PLAN-全仓命名统一后续批次-原子级执行计划.md`（合并后删除原文件）。

## 0. 总则

1. **一人一义**：同一实体在全栈只有一个英文名与一个 SQLite 列名（snake_case），IPC/JSON 只有一个 camelCase 键。
2. **禁止糊弄**：禁止 serde alias、禁止双键读写、禁止「DB 旧名列 + DTO 新字段」的映射层糊弄。
3. **批次原子**：每个批次单独合并主干；合并前 `cargo check` + `cd ui && npm run build`。
4. **kind / 命令改名**：凡改 `ai_tasks.kind`、`ai_queue_tasks.task_type`、Tauri command 名，必须同一批次内完成 Rust + 前端 `invoke` + DB `UPDATE`（幂等）+ `main.rs` 注册表 + 文档。
5. **见名知义**：`chapter` = 剧集节点，`scene` = 场次节点，`segment` = 片段/镜头节点。禁止用泛词 `board` 兼指「剧集多场次文本规划」与「故事板画布 StoryboardGraph」。

## 1. 冻结词表（唯一合法命名）

### 1.1 故事根（stories / storyId）

| 层级 | 唯一命名 | 含义 |
|------|-----------|------|
| SQLite 表 | **`stories`** | 原 `projects` 表已更名 |
| SQLite 列（外键） | **`story_id`** | 禁止继续叫 `project_id` |
| SQLite 主键 | **`stories.id`** | 语义上即对外 `storyId` |
| Rust | **`story_id`** | IPC 序列化 `storyId` |
| TS / IPC | **`storyId`** | 唯一表示故事根 id 的键 |

**禁止**：在本仓库自有协议与自有持久化中出现 `projectId` / `project_id` / `projects` 表名表示故事根。第三方 HTTP/SDK 若字段名由厂商固定为 `projectId`，仅在紧贴边界的 adapter 类型中保留，不得穿透进 IPC、DTO、`ai_tasks` JSON、前端状态。

### 1.2 剧集节点（chapterNodeId）

| 层级 | 唯一命名 |
|------|-----------|
| SQLite 列 | **`chapter_node_id`**；追溯 **`trace_chapter_node_id`** |
| Rust | **`chapter_node_id`** / **`chapter_node_ids`** |
| TS / IPC | **`chapterNodeId`** / **`chapterNodeIds`** / **`traceChapterNodeId`** |

**禁止**：`chapterId` / `chapter_id` / `chapter_scope_id` / `chapterScopeId` 表示「剧集节点 id」；禁止 `trace_chapter_id`；禁止 `contextChapterId`（应为 `contextChapterNodeId`）。

### 1.3 场次节点（sceneNodeId）

| 层级 | 唯一命名 |
|------|-----------|
| SQLite 列 | **`scene_node_id`**；追溯 **`trace_scene_node_id`** |

| TS / IPC | **`sceneNodeId`** / **`traceSceneNodeId`** |

**边界**：英文 UI 统一用 **Scene**（已替换 Beat）；中文 UI 用「场次」。

### 1.4 片段节点（segmentNodeId）

## 2. 管线 kind / command 命名规则

### 2.1 单场/剧集级 kind

| 概念 | 已落地 kind | 说明 |
|------|-------------|------|
| 剧集级多场次规划 | `chapter_scenes_plan` | 原 `chapter_scenes_board` |
| 单场文本规划多镜 | `scene_shots_plan` | 原 `scene_storyboard_shots` |
| 片段级分镜静帧图 | `segment_storyboard_image` | 未改名（无歧义） |
| 队列 task_type | `segment_shots_plan` | 原 `segment_storyboard_shots` |

### 2.2 批量 kind（格式：`{scope}_{artifact}_{batch}`）

| 已落地 kind | 说明 |
|-------------|------|
| `story_scenes_shots_plan_batch` | 全故事批量父任务 |
| `chapter_scenes_shots_plan_batch` | 剧集内批量父任务 |

**格式规则**：
- **scope**：`story`（全故事）/ `chapter`（剧集内）
- **artifact**：`scenes_shots_plan`（与单场 `scene_shots_plan` artifact 一致）
- **batch**：固定后缀

### 2.3 常量定义位置

- **Rust**：`src-tauri/src/ai_task_kinds.rs`（`pub const`）
- **DB 迁移**：已删除（旧增量迁移 `storyboard_ai_task_kind_names.rs` 已移除，kind 常量仅由 `ai_task_kinds.rs` 承载）
- **前端**：禁止手写散落字符串，应 `import` 单一常量模块

### 2.4 不改名的 kind

`scene_concept_image`、`segment_storyboard_image`、`role_portrait`、`settings_model_validate` — 不含 `board` 双关歧义。

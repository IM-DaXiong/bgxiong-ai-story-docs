## 关于源项目

比格熊数字导演工作站（bgxiong-ai-story）是一套 AI 驱动的桌面端影视创作平台：

- **技术栈**：Tauri 2（Rust）+ React 19 + TypeScript 5.9 + SQLite
- **代码规模**：约 198 万行有效代码（2026-11-12 口径，见 [项目综述-最新版](./01-项目概览/项目综述-最新版.md)）
- **核心理念**：本地优先、数据主权、直连 API、不降级不兜底
- **产品形态**：Windows 桌面客户端（非 SaaS / 非网页套壳）
- **现行架构**：以 [20261104-ARCH-全仓整体架构设计](./02-架构设计/20261104-ARCH-全仓整体架构设计.md) 为准

## 关于源项目

比格熊数字导演工作站（bgxiong-ai-story）是一套 AI 驱动的桌面端影视创作平台：

- **技术栈**：Tauri 2 (Rust) + React 19 + TypeScript + SQLite
- **代码规模**：~73 万行自研代码
- **核心理念**：本地优先、数据主权、直连 API、不降级不兜底
- **产品形态**：Windows 桌面客户端（非 SaaS / 非网页套壳）

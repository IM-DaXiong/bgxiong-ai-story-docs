# 故事板双栏画布 · 布局与排障经验（长期）

> **适用**：故事板 Tab 中间「分镜工作流画布」+ 右侧「分镜历史列」及二者之间的可拖拽分栏。  
> **原则**：凡画布类 BUG，**先读 `logs/frontend-*.log`**，再按本文「排障顺序」对号入座；**禁止盲猜改 UI**。

## 2. 接入约定（新增/改版必读）

### 2.1 分镜历史列 · 通用瀑布流画布

- **必须**走 `useMasonryCanvasLayout` + `InfiniteCanvas` + `MasonryCanvasLayoutGate`（与 PadPicker / 演员定妆同族）。
- **禁止**自研 pan/zoom/小地图/框选（旧 `useShotHistoryCanvas` 手写版已废弃）。
- **存储键**：`storyboardShotHistoryCanvasV1StorageKey(segmentNodeId)`（`ui/src/infinite-canvas/layout/canvasLayoutStorageKeys.ts`）。
- **scopeKey** = 当前选中分镜 `segmentId`；切换分镜自动 hydrate 该分镜的视口/瓦片坐标。
- **小地图**：右下角**始终可见**（勿用 `canvasFullscreen` 门控）。
- **勿传** `renderPlaceholder`：PadPicker 模式不传时，IC 占位阶段仍走 `renderNode`；传了会出灰色块 + `mountedIds` 竞态（**BUG-2026-05-28-004**）。
- **图片 URL**：`getPortraitImageSrcAsync` 异步；须 `historySrcHydrated === true` 后再挂载 IC（`canvasReady = layoutReady && historySrcHydrated`）。按分镜内存缓存 `srcCacheBySegmentRef` 加速切回。
- **拖出至工作流**：见 **§2.1.1**（PLAN 冻结交互；**禁止**在 IC 未修 `mouseleave` 前靠猜改探针）。

#### 2.1.1 分镜历史 → 工作流 · 导出拖（REQ-002 · 长期 SSOT）

**产品（冻结）**：历史列内 = 布局拖；指针或瓦片中心进入工作流可拖入区 = 导出拖（幽灵 + 源图钉 `originPos`）；**仅真实 mouseup** 且指针在工作流区内才建参考图；导出拖按住期间不因指针回到历史而退出。

**代码入口**：

| 层 | 文件 |
|----|------|
| 会话 / 探针 / drop | `hooks/useShotHistoryCanvas.ts` |
| 可拖入区 | `storyboard-shot-canvas/canvasDropWorldBridge.ts` → `isPointerInWorkflowDropZone` |
| 屏幕→世界 | `StoryboardShotCanvas.tsx` → `workflowCanvasDropWorldRef` |
| 钉住 + commit | `InfiniteCanvas.tsx` → `exportDragPinNodeIdRef`、`resolveNodeDragCommitPositions` |
| 幽灵 | `history/ShotHistoryExportDragGhost.tsx` |
| 接线 | `StoryboardTabActive` refs：`workflowColumnDropZoneRef`、`historySplitBoundaryRef`、`workflowCanvasScreenRectRef` |

**关键机制**：

1. **跨列指针**：历史 IC 宿主外仍要跟手 → `document` capture `mousemove`/`mouseup`（`attachExportDocumentMoveListener`）。  
2. **假松手**：指针离开历史 IC DOM → `mouseleave` 曾触发 IC `handleMouseUp` → 须 `buttons&1` 时 **skip commit**（BUG-017）。  
3. **松手坐标**：`phase:'release'` → `session.releasePointer`；commit 禁止用最后一帧 move（BUG-015）。  
4. **钉住提交**：`exportDragPinNodeIdRef` 命中时 IC commit **仅 originPos**；父级 `setTilePositions(merged)` 同值；否则 `dragPositions` 滞留视口外（BUG-018）。  
5. **进入判定**：`exportActive = exportMode || inWorkflowZone`；`inWorkflowZone` = 指针或虚拟中心在 `isPointerInWorkflowDropZone` 内。

**详表与日志**：`docs/dev/plans/20260528T160000+0800-PLAN-分镜历史拖入工作流参考图-双画布交互开发计划.md`。

### 2.2 工作流画布

- SSOT：`StoryboardShotCanvas`；重置节点布局走 Rust `computeStoryboardResetLayout`（`handleCanvasResetNodeLayout`）。
- **视口**按 `graphScopeKey`（场次）持久化；勿与 `segmentId` 混用。
- **删除**须走 `storyboard-canvas-delete` 域（**INV-DEL**）；禁止 parallel Delete 入口。

### 2.3 中间分栏宽度

- Catalog：`workspaceCatalog` → `storyboard.tab.workflow` → `split.shotHistoryPaneWidth`（**仅 `default: 340`，无 min/max**）。
- `SplitSchema.min/max` 可选；未配置时拖拽仅 clamp ≥0。
- 工作流列宽 = 父容器剩余空间（flex），**不**读 `shotHistoryPane.size` 间接推算。

## 3. 「重置画布」宽度契约（强制）

| 画布 | 重置入口 | 宽度来源 | 说明 |
|------|----------|----------|------|
| 工作流 | `StoryboardShotCanvas.resetCanvasLayout` | double `rAF` 后 `rootRef.clientWidth - 32` | 反映**拖分栏后**中间列实际宽度 |
| 分镜历史 | `useShotHistoryCanvas.resetCanvasLayout` → `resetLayoutPersist` | 重置前 **`containerRef.clientWidth` 强制 remeasure** | 再清 LS + 瀑布流重算；勿仅用旧的 RO 缓存或 `shotHistoryPane.size` fallback |

**验收**：拖宽/拖窄历史列 → 点「重置画布」→ 历史列瀑布流列数、工作流节点排布均应匹配**当前**列宽。

**日志**：

- 工作流：`[STORYBOARD_CANVAS] commit viewport` / reset layout API 前后
- 历史：`CANVAS_MASONRY_LAYOUT reset_layout_remeasure` · `STORYBOARD_SHOT_HISTORY_CANVAS reset layout`（含 `hostWidth` / `paneWidth`）

## 5. 排障 Playbook（遇到画布问题先走此表）

### 5.0 第一步（强制）

1. 打开 **`logs/frontend-YYYY-MM-DD.log`**（故事板操作时段）。
2. 若无可用前缀 → **先补日志**再改代码（`ui/src/utils/logger.ts` · 固定前缀）。

### 5.1 分镜历史 · 图片不显示 / 长期占位

| 步骤 | 检查 | 日志键 |
|------|------|--------|
| 1 | 是否 `historySrcHydrated` 未 true 就挂了 IC | `STORYBOARD_SHOT_HISTORY_SRC hydrate start/done` |
| 2 | `localCachePath` 是否为空被过滤 | 后端 portrait 版本 JSON |
| 3 | 是否误传 `renderPlaceholder` | 代码审查 `StoryboardShotHistoryColumn` |
| 4 | `layoutReady` 是否 false（aspect / containerWidth） | `CANVAS_MASONRY_LAYOUT layout_commit` · `container_width` |
| 5 | `mountedIds` 是否卡占位 | 对比 PadPicker（无 renderPlaceholder） |

### 5.2 重置后布局与当前列宽不符

| 步骤 | 检查 | 日志键 |
|------|------|--------|
| 1 | 历史：重置前是否有 `reset_layout_remeasure` | `CANVAS_MASONRY_LAYOUT` |
| 2 | 工作流：`hostWidth` 是否合理 | `StoryboardShotCanvas` reset 内 rAF |
| 3 | 是否用了 `widthFallbackPx` 而非实测（containerWidth &lt; 100） | `layout_commit` 的 `containerWidth` |

### 5.3 拖分栏后一侧画布空白/挤压

| 步骤 | 检查 |
|------|------|
| 1 | `shotHistoryPane.size` 与历史 `Panel` width 是否一致 |
| 2 | 工作流 `rootRef` 是否 `flex:1` 且父级 `minWidth:0` |
| 3 | `usePersistentSplit` 是否仍带 catalog min/max（应已移除） |

### 5.4 工作流 · 视口/选中/删除异常

- 视口不记忆 → `graphScopeKey`、BUG-2026-05-27-003、`[STORYBOARD_CANVAS] commit viewport`
- Delete 后闪 loading → BUG-2026-05-28-001（勿 `refreshSegments` 卸画布）
- 拖参考图后选中跳分镜 → BUG-2026-05-28-002（`canvasSelectedIdSyncRef`）

### 5.5 与工作流 ↔ 历史联动

- 历史 → 工作流参考图：`STORYBOARD_HISTORY_TO_CANVAS_REF` · `STORYBOARD_REF_AUX`
- 参考图/默认图/删除：历史列右键 → 与 `useShotPortraitDefault` 同源

### 5.6 分镜历史 → 工作流 · 导出拖（专用 Playbook）

| 现象 | 优先查 | 典型根因 |
|------|--------|----------|
| 过线立刻建节点、未松手 | `InfiniteCanvasDrag` 是否有 commit；是否缺 `mouseleave skip` | BUG-017：`mouseleave` 当 mouseup |
| 松手无节点 / `hasWorld:false` | `export release commit probe` · `workflowColumnBound` · `workflowCanvasRectBound` | column/rect ref 未绑；指针仍在历史列（`releaseClientX` vs `splitLeft`） |
| 过线误建参考图（历史列松手） | `drop` 时 `pointerInHistoryHost` | BUG-015：用瓦片中心当落点 |
| 无幽灵 / 无 `export drag started` | `export probe` 全程 `pointerInHistoryHost:true` | 仅指针探针；须拖中心过线或补虚拟中心（BUG-016） |
| 建节点后右侧源图消失 | `export revert` 后 IC `dragPositions` | BUG-018：pin commit 须 originPos |
| 拖第二张第一张复位 | `in-panel layout commit` 的 `positionKeys` | 未整表 `setTilePositions`（BUG-013） |
| 导出闪断 ~15ms | `export drag ended` 在 move 中 | 曾用中心回历史退出；现 `exportMode` 保持至松手 |

**推荐日志顺序**：`drag state true` → `export drag started` → `ghost frame`（多帧）→ `export release pointer` → `export release commit probe` → `drop on workflow canvas` **或** `export release cancelled` → `export revert merged positions`。

**改动门禁**：动 `InfiniteCanvas` 拖拽 commit / `mouseleave` 时，必须复测本表全部行。

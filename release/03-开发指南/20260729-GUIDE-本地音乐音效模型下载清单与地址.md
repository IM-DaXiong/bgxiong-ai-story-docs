## 3. 推荐下载命令

目标目录以仓库根为 cwd。

### 3.1 音乐（ModelScope CLI，国内优先）

本机已装 `modelscope` 时**优先用 CLI**（与 `modelscope download --model … --local_dir …` 等价；当前 CLI 亦支持位置参数 `repo_id`）：

```bash
# 主包（开箱；已完成可跳过）— 可先下到临时目录再拷入 checkpoints
modelscope download ACE-Step/Ace-Step1.5 --local-dir d:/00dev/models-download
# 或直接落到本仓：
modelscope download ACE-Step/Ace-Step1.5 --local-dir runtimes/music/acestep/checkpoints

# 增强包（缺哪个下哪个；local-dir 必须是对应子目录）
modelscope download ACE-Step/acestep-v15-sft --local-dir runtimes/music/acestep/checkpoints/acestep-v15-sft
modelscope download ACE-Step/acestep-v15-base --local-dir runtimes/music/acestep/checkpoints/acestep-v15-base
modelscope download ACE-Step/acestep-5Hz-lm-0.6B --local-dir runtimes/music/acestep/checkpoints/acestep-5Hz-lm-0.6B
modelscope download ACE-Step/acestep-v15-xl-turbo --local-dir runtimes/music/acestep/checkpoints/acestep-v15-xl-turbo
modelscope download ACE-Step/acestep-v15-xl-sft --local-dir runtimes/music/acestep/checkpoints/acestep-v15-xl-sft
modelscope download ACE-Step/acestep-v15-xl-base --local-dir runtimes/music/acestep/checkpoints/acestep-v15-xl-base
```

批量脚本（串行、写 `logs/music-modelscope-download.log`）：

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/_run-music-modelscope-download.ps1
```

Python API 等价：

```bash
python -c "from modelscope.hub.snapshot_download import snapshot_download; snapshot_download('ACE-Step/acestep-v15-sft', local_dir=r'runtimes/music/acestep/checkpoints/acestep-v15-sft')"
```

或官方 ACE-Step CLI（需先装 ACE-Step）：

```bash
uv run acestep-download --all --download-source modelscope
# 或
python -m acestep.model_downloader --all --download-source modelscope
```

并保证 checkpoints 指向本仓：

```bash
set ACESTEP_CHECKPOINTS_DIR=D:\00Dev\bgxiong-ai-story\runtimes\music\acestep\checkpoints
```

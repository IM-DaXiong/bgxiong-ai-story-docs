# 比格熊数字导演工作站 — 项目概要

> **版本**：v0.3.801 · **更新日期**：2026-07-24 · **代码规模**：~73 万行（Rust ~28.5 万 + TS/TSX ~39.5 万）

---

## 一、产品定位

比格熊数字导演工作站（bgxiong-ai-story）是一套 **AI 驱动的多模态故事与分镜工作台**，产品形态为安装在电脑上的 **桌面客户端**。它将故事结构（项目→剧集→场次→片段/镜头）、角色与演员资产、分镜故事板，以及文本/图像/视频/语音生成链路放在 **同一套本地工程与同一应用窗口** 里闭环完成，面向影视、短视频、动漫与教育实训等 **前期创意与试制** 场景。

**核心理念**：用 AI 将「一句话故事」自动拆解为完整的可视化制作管线——从故事种子到剧集、场次、镜头、分镜图、视频成片，全链路自动化，大幅降低短视频与动画制作门槛。

---

## 二、核心痛点与解决方案

| 痛点 | 解决方案 |
|------|----------|
| **故事到可视化全链路手工操作、工具碎片化** | 自动化管线：故事→剧集→场次→镜头→分镜→视频，一键贯通 |
| **AI 厂商接口各异，切换成本高** | 统一端点注册表（open_platform），即梦/可灵/通义万相/Seedance/OpenAI 一键切换 |
| **跨百张分镜帧角色形象不一致** | 演员/角色/肖像版本链管理，角色特征自动注入每级 AI 提示词 |
| **多工具并行导致上下文断裂、素材散落** | 本地工程统一承载，文案/图像/视频/语音同一窗口闭环 |
| **AI 结果不可追溯、无法复盘** | 最终提示词强制落盘、任务三阶段全程可查、版本历史可回溯 |

## 三、架构优势（非云端套壳）

本项目是 **真正的本地优先桌面客户端**，非简单网页封装或云端套壳：

### 3.1 本地化运行，数据主权在用户手里

- **本地 SQLite 数据库 + WAL 模式**：所有故事、角色、场次、任务数据完整落盘本地，断网可用、数据自主掌控
- **40+ 张数据表**：覆盖故事结构、画布状态、AI 任务、媒体轨道、权限等全领域
- **字段命名规则统一**：冻结词表 + SSOT 索引，数据库、对外接口与界面之间命名一致

### 3.2 直连官方 API，不降级、不中转

- **用户选了什么模型，系统就用什么模型**：不会偷偷换通道，不会静默兜底
- **每一次生成请求，都是从用户电脑直连到模型厂商的官方 API**：没有中间服务器转发
- **统一端点注册表**：新增厂商只需注册新端点，业务管线零侵入，可持续升级

### 3.3 桌面客户端的天然优势

- **不绑死在浏览器标签页的生命周期**：关闭浏览器、清理站点数据不会丢失工作
- **更深地接入本机能力**：日志与诊断、数据目录配置、ComfyUI 本地工作流、FFmpeg 媒体运行时
- **复杂界面与大体量交互敢往深了做**：大面积无限画布、多标签重度工作台、长列表任务中心
- **隐私与对内合规更好叙事**：敏感台词与设定默认留在本机

### 3.4 自研基础设施

- **自研无限画布内核**：四叉树空间索引、masonry 布局、虚拟化渲染、LOD 分级、资源回收，支撑数百节点量级流畅交互
- **通用有向图引擎（GraphCore）**：统一支撑分镜故事板、片段画布等多个画布场景的节点连线与关系管理
- **模块化管线设计**：故事→剧集→场次→镜头→分镜→视频各阶段独立，可单独执行、可组合、可替换
- **可插拔权限框架**：权限后端、装饰器、审计日志、缓存层，面向机构采购与团队使用

## 四、核心逻辑流

```
故事 → AI 生成剧集 → AI 生成场次 → AI 生成片段/镜头
     → AI 生成分镜图 → AI 生成视频 → TTS+唇形同步 → 成片
```

- **分阶段 LLM 级联管线**：每阶段产出结构化 JSON 作为下一级输入，含叙事一致性审核与 Story Bible 提取
- **角色一致性上下文**：每级提示词自动注入出场角色外貌描述与参考图
- **AI 队列系统**：并发执行、限流、重试、暂停/恢复，任务生命周期全可追踪

## 八、主要功能模块

### 8.1 故事管线
- 故事→剧集→场次的 LLM 级联生成
- 场次规划粒度 lint 与修复
- 故事圣经同步管线、故事风格域 SSOT

### 8.2 分镜引擎
- 分镜生成（Stage A 语义层 + Stage B 渲染层）
- 导演化语义注入、质量门校验、连贯性管理
- 电影语言体系（画面构成枚举、场次规划粒度 lint）
- 批量静帧生图、提示词版本历史

### 8.3 角色与演员
- 全局可复用演员库、角色定妆照生成
- 演员仅锁五官 / 剧情驱动服化道年龄
- 肖像版本链、多视角参考图、定妆描述智能优化

### 8.4 片段画布（Clips）
- 无限画布引擎、视频片段 CRUD、导入导出
- 画布状态全量持久化、瓦片缩略图 LOD
- 导出全部：指定媒体目标目录、字节级拷贝进度（对齐 DataMigration 模式）
- FCPXML 媒体路径修复（canonical 绝对路径）

### 8.5 修图工作台
- NL 修图（自然语言指令修图）、画笔/裁切工具
- 旋转功能（任意角度 + 90°/180°/270° 预设，简化为统一 expanded 语义）
- 多区域关联指令、快速选择画笔
- 直连模型独立弹窗、imperative 渲染引擎

### 8.6 视频生成管线
- 多家视频模型统一调度
- 5 种唇形同步适配器、TTS 语音合成、字幕生成与烧录

### 8.7 本地桥接（Local Bridge）
- 达芬奇插件对接（HTTP 信封协议 + 传输层鉴权）
- 母带预处理：异步 Job + GPU 加速（Win 默认 NVENC）、POST 202 + poll 不阻塞 UI
- 母带 A/V 精确合并：8 路 filter_complex 树合并 + trim 契约，误差 0ms
- 母带无损拼装快路径：同源 I 帧吸附 + stream copy
- 自动剪辑（autocut）：字幕+时间码→LLM 去重/纠错→FCPXML 三方重构→插件 Import Apply→outbox 推送
- 高光切片（highlight）：校验→prompt→LLM→解析→校验全管线
- 字幕识别（subtitle.recognize）：Whisper 本地语音识别
- 语音裁剪（speech trim）：基于字幕时间码的语音块分割

### 8.8 本地 AI 能力
- llama.cpp 文本推理（含 llama-server 灵活模型加载）
- Whisper 语音识别（whisper-cli 外挂运行时，非编译进主程序）
- 通用文件下载模块（进度条/断点续传/SHA256）
- 本地模型权重目录管理

### 8.9 ComfyUI 集成
- HTTP/WebSocket 双协议客户端
- 工作流扫描与编译器、占位符注入
- 自定义工作流支持

### 8.10 媒体运行时
- FFmpeg CLI 统一封装（定位、参数构建、执行、探测解析）
- 媒体能力注册与格式选择
- 视频转码、音频提取、字幕合成

### 8.11 设置与管理
- 账号绑定、能力映射（模型列表顺序全局可控）
- 本地模型管理（llama.cpp + Whisper）、TTS/视频实验室
- 诊断与数据存储、BUG 报告、自动更新

## 十、产品优势总结

1. **真正的本地优先**：数据在用户手里，断网可用，隐私有保障
2. **直连官方 API**：不降级、不中转，成本透明，速度更快
3. **统一模型调度**：一家新模型接入，全管线可用
4. **全链路自动化**：从一句话故事到视频成片，AI 全程辅助；母带预处理/合并自动化，达芬奇无缝对接
5. **~73 万行自研代码**：不是套壳 API 聚合器，是真正的生产力工具
6. **可追溯可审计**：每一次生成请求都有记录，合规无忧
7. **达芬奇插件生态**：本地桥接对接达芬奇 Resolve，自动剪辑 FCPXML 三方重构、母带 A/V 精确合并、Whisper 语音识别全管线

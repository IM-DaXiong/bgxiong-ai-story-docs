## 2. 后端：`src-tauri/`

### 2.1 工作区

- 主 crate 是 GUI 宿主（包名与编译身份版本固定，发版数字写在 `tauri.conf.json`）。
- `src-tauri/crates/` 现有 **20** 个子 crate（19 个已登记角色，`bgx-adapter-v2-media-host` 尚未登记），按 pure-core / infrastructure / runtime / transport / tool / build-support 登记角色。清单见 [全仓整体架构设计 §4](../02-架构设计/20261104-ARCH-全仓整体架构设计.md)。
- `src-tauri/src/` 是宿主源码根：约 154 个顶层目录、162 个顶层源文件、约 3,834 个 `.rs` 文件。

### 2.2 宿主分层目录

| 目录 | 职责 |
|------|------|
| `commands/` | 较薄的 Tauri 命令入口，参数转换后委托下层 |
| `application/` | 用例、端口与 DTO，不直接写 SQL |
| `domain/` | 纯类型、值对象与规则 |
| `infrastructure/` | 持久化等基础设施适配，SQLite 实现集中于此 |
| `platform/` | 操作系统能力接口与桌面实现 |
| `composition/` | 组装注入，不承载业务实现 |
| `db/` | 连接池、schema 编排与迁移入口 |

### 2.3 业务竖条（按产品方向）

除分层目录外，其余顶层模块按能力切分。现行主线与存量边界如下：

| 方向 | 代表模块 | 说明 |
|------|----------|------|
| 片段创作主线 | `clip_workflow`、`clip_framework`、`segment_canvas`、`video_span`、`story_creation`、`script_segment` | 故事 → 剧集 → 片段 |
| 画布 | `free_canvas`、`canvas_*`、`media_canvas`、`graph_core`、`workflow_graph_store` | 自由画布、媒体节点、图存储 |
| 角色与资产 | `visual_asset`、`portrait_*`、`appearance`、`story_prop*` | 演员 / 角色 / 肖像 / 道具 |
| 生成管线 | `image_generation`、`segment_video_pipeline`、`video_prompt_*`、`open_platform` | 生图、生视频、提示词、统一调度 |
| 声音 | `speech`、`voice_studio`、`music_generation`、`sfx_generation`、`asr`、`singing_relyrics` 等 | 配音、音乐、识别、翻录转唱 |
| 后期与交付 | `production_delivery`、`auto_edit`、`postproduction_decoration`、`clips_export` | 剪辑交付、模板与导出 |
| 智能体与扩展 | `assistant_agent`、`creator_tools`、`adapter_host`、`agent_skills`、`content_skill_host`、`comfyui` | 助手、MCP 创作协议、适配器、Skills、ComfyUI |
| 数据与运行时 | `story_backup`、`project_sync`、`runtimes`、`media_runtime` | 备份包、工程同步、本地运行时 |
| 旧编排存量 | `chapter_scenes_plan`、`storyboard_*`、`clips` | 不再扩展，禁止整目录删除 |
| 账号 / 授权 / 商业化 | 存在相应模块 | **开源版已省略实现说明** |

## 3. 前端：`ui/src`

截至 2026-11-12，`ui/src` 约有 6,592 个 TypeScript / TSX 文件。分层与规模：

| 目录 | 约略规模 | 职责 |
|------|----------|------|
| `domain/` | 约 262 个子目录、3,997 个文件 | 纯前端逻辑，不直接发起桌面调用 |
| `components/` | 约 123 个子目录、1,693 个文件 | 界面组件 |
| `infinite-canvas/` | 约 197 个文件 | 自研无限画布内核 |
| `features/` | 约 203 个文件 | 角色 / 演员等标签页（历史场次标签已不再作为独立日常入口） |
| `application/` | 较少，正在承担保存等用例 | 组合多次调用的用例 |
| `api/`、`tauri/` | 约 56 + 11 个文件 | 桌面调用封装 |
| `app-shell/`、`boot/`、`popout-apps/` | 外壳、启动、弹出窗口 | 主窗口之外还有全局助手窗口；`ui/` 下约 21 个 HTML 入口 |
| `settings/`、`help-module/`、`i18n/`、`theme/`、`three-d/` 等 | 设置、帮助、国际化、主题、3D 辅助 | 设置中与账号或凭证相关的部分开源版不展开 |
| 认证相关目录 | — | **开源版已省略实现说明** |

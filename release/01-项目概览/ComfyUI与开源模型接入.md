# 云端 API + 本地引擎：比格熊可能是唯一把两条路都走通的 AI 创作平台

> 一边是火山引擎、通义千问、即梦、可灵等云端大厂的旗舰模型，另一边是 ComfyUI、IndexTTS-2、VoxCPM2 等开源社区的顶尖引擎。比格熊用一套统一调度层，把两条路接在了一起——云端有云端的强，本地有本地的香，而你只需要决定"今天用哪个"，不需要纠结"这个能不能用"。

---

## 一个平台，两条腿走路

在 AI 创作工具的世界里，一直存在着一个两难选择：

**选云端平台**，模型强、更新快、不用折腾环境，但按量计费、数据上传、批量生成时账单跳得比心跳还快。

**选本地开源引擎**，免费、隐私、无限制，但环境配置劝退、模型管理繁琐、跟创作工具之间隔着一层"手动导出导入"的墙。

两拨用户各自忍受着另一半的缺失。而比格熊做的事情，就是把这两条路**接在一起**——不是二选一，是两全其美。

比格熊的上层是六家云端大厂——火山引擎、通义千问、即梦 AI、可灵 Kling、DeepSeek、OpenAI 兼容网关——加上 ComfyUI、IndexTTS-2、VoxCPM2 等本地开源引擎，作为两条并行的动力来源。中间是一层**统一调度引擎**，它把文本、图片、视频、语音四类 AI 能力的调用全部收敛到同一个入口。上层业务——角色定妆、分镜生图、台词配音——只跟这个调度层对话，完全不关心底层跑的是云端还是本地。用户面对的始终是同一个按钮、同一种操作，切换引擎只是后台一个偏好设置的事。

### 举一个真实的场景

你在做一个短片。剧本文本是 DeepSeek 帮你润色的，角色定妆照用**可灵 Kling** 生成——云端大模型画质确实能打。到了分镜环节，20 个镜头逐一生成静帧，这时候你切换到**本地的 ComfyUI**——免费、无限量、不怕批量跑一晚上。

配音环节，主角的台词你用**火山引擎**的高品质云端 TTS，追求自然度；群杂背景音你用**本地的 VoxCPM2** 批量合成，量大管饱不花钱。

**从头到尾，你只打开了比格熊这一个软件。** 云端还是本地、花钱还是免费、追求质量还是追求效率——这些选择不再是"你用什么工具"的问题，而仅仅是"这个任务你偏好哪个引擎"的问题。点一下切换按钮的事。

这就是双引擎架构真正带来的自由。

## 云端篇：六大厂商，旗舰模型，开箱即用

先看云端。比格熊预置了 **6 家云端 AI 厂商**的接入模板。

火山引擎和通义千问是"全能型选手"——文本理解、图片生成、视频生成、语音合成四项能力全部覆盖，一家账号就能打通四种创作需求。即梦 AI 和可灵 Kling 专攻视觉方向，主打图片和视频生成，在画面质感上有各自的看家本领。DeepSeek 聚焦文本理解，适合剧本润色和文案创作。OpenAI 兼容网关则为习惯 OpenAI 生态的用户提供了熟悉的接入方式。

每家厂商在系统里都有一份精确的能力白名单，限定"哪个接口能做哪种任务"。你在设置里不会看到 DeepSeek 出现在"视频生成"的选项里，也不会被问到"即梦 AI 的文本模型选哪个"——系统在底层就帮你理清楚了。

新用户第一次打开软件，所有厂商的接入模板已经就位。你只需要去对应厂商官网申请一个 API Key，填进去，立即就能用。**一个账号可以同时绑定多个能力**：比如你在火山引擎注册了一个账号，文本生成、图片生成、视频生成、语音合成全部共享这一套密钥，不需要每个功能重新配置一遍。

## 本地篇：三大开源引擎，一次部署，永久免费

再看本地。比格熊全量接入了三个各自领域的开源顶流：

### ComfyUI：你的私人图片 + 视频工厂

如果你关注过 AI 绘画，一定听过 Stable Diffusion。而 ComfyUI 就是为它打造的"终极驾驶舱"——把生图生视频的每个步骤变成一个个可视化的节点，像搭乐高一样连线，就能搭出专属的生产线。高手用它，一张图里三个角色各具姿态、背景有景深层次、光影风格统一。不只静态图，它还能生成高质量 AI 短视频——从文生视频到图生视频，全在一条工作流里搞定。跑在你自己的 GPU 上，每一张图、每一段视频都属于你自己。

### IndexTTS-2：会"演戏"的语音合成

传统 TTS 只能把字"念"出来，毫无感情。IndexTTS-2 不仅能克隆任何人的声音，还能精确控制合成语音的情绪——用文字描述情绪、用参考音频传递情感、甚至用向量微调情感强度，三种方式从粗到细。它在中文语音的韵律、停顿、语气词处理上是开源界第一梯队水平，面向中文观众的创作者不容错过。

### VoxCPM2：零样本声音克隆的"全能选手"

几秒钟的参考音频，就能用那个人的声音说出任意内容，中英文都行，无需训练。更惊艳的是**声音设计**——你甚至不需要真实参考音频，用文字描述"一位慈祥的老奶奶，声音温暖缓慢"，它就能直接合成出对应的声音。还支持**续录克隆**，哪怕只录了三秒，系统也能边生成边优化声音特征，非常贴近真实使用场景。

## 统一调度层：云端和本地的"同声传译"

如果只是把云端 API 和本地引擎各自接进来、然后让用户自己选，那叫"两套系统塞进一个壳"。比格熊走的比这远得多。

我们在云端和本地之上建了一层**统一调度引擎**。文本、图片、视频、语音——每一类 AI 能力只有**一个调度入口**。当你的分镜需要生成一张图时，调度层收到指令，然后根据你当前的偏好设置，把请求转发给可灵 Kling、即梦、通义万相，或者本地的 ComfyUI。

**对你来说，操作完全一样。** 同样是"为这个分镜生成画面"，不管你后台选的是云端模型还是本地引擎，你面对的是同一个按钮、同一种操作、同一套反馈。你甚至可以在设置里给不同任务指定不同的偏好引擎——角色定妆用云端追求极致画质，批量分镜用本地节省成本——一次设置，后面全自动。

这才是真正的"双引擎"：不是两套割裂的体验拼在一起，而是**一个统一的创作界面，底下有两套动力系统随你切换**。

## 比双引擎更重要的，是它跑在专业工作流里

引擎再强，孤零零放着也只是引擎。比格熊把云端和本地的 AI 能力全部**嵌入到影视创作的具体环节**里：

**角色定妆**：写好角色描述 → 选择云端或本地引擎 → 一键生成多角度定妆照。提示词、参考图、风格预设全部从你编辑的内容中自动提取，不需要手动复制粘贴。

**分镜批量生成**：在画布上排好 20 个分镜卡片，每格写好了画面描述，有些要静态图、有些要短视频预览。过去你要一个一个导出、一个一个丢进不同工具——现在**全选 → 批量生成 → 等出片**。系统自动管理任务队列、失败重试，生成结果直接回填到对应卡片上。你只负责验收。

**角色配音**：每个角色绑定专属"声音档案"——可以用火山引擎云端 TTS 追求播报级自然度，也可以用 IndexTTS-2 或 VoxCPM2 本地引擎免费用。写好台词 → 选中 → 批量合成。系统自动匹配角色对应的声音和情绪参数，几分钟后所有音频全部就绪，直接拖进视频时间线。

### 智能调度，不让电脑白跑一秒钟

批量提交几十个任务时，调度引擎会自动根据你的 GPU 显存和算力动态调整并发数，不会把电脑卡死。任务失败自动重试，关电脑也不怕——下次打开软件，从断点继续跑，已完成的不重复生成。

### 一次部署，后面只管创作

三个本地引擎的原生安装加起来能劝退 90% 的用户：Python 环境、CUDA 版本、依赖冲突、权重下载……每一步都可能踩坑。在比格熊里，打开设置 → 选择引擎 → 点击安装，剩下的全部自动完成。系统会检测你的显卡能不能跑、显存够不够，给你明确的建议。**部署只需一次，之后打开软件引擎自动就绪。**

### 1.2 技术栈选型

| 层级 | 技术选型 | 选型理由 |
|------|----------|----------|
| **桌面壳** | Tauri 2 | Rust 进程托管，安装包小（~10MB），内存占用低，非 Electron 重型 Webview |
| **前端框架** | React 19 + TypeScript 5.9 + Vite | 组件化开发，类型安全，快速热更新 |
| **后端语言** | Rust (edition 2021) | 内存安全，高性能，适合系统级编程 |
| **数据库** | SQLite (WAL + r2d2) | 本地优先，零配置，WAL 模式支持并发读写 |
| **异步运行时** | Tokio (多线程) | 高性能异步 I/O，适合 AI 任务并发 |
| **HTTP 客户端** | reqwest 0.13 | 支持 HTTP/2、gzip、multipart、stream |

## 5. AI 调度架构

### 5.1 统一端点注册表

```rust
// 端点注册表结构
pub struct EndpointRegistry {
    providers: HashMap<String, Box<dyn AiProvider>>,
    dispatch_rules: Vec<DispatchRule>,
}

// 厂商适配器 trait
pub trait AiProvider {
    fn name(&self) -> &str;
    fn capabilities(&self) -> Vec<AiCapability>;
    async fn generate(&self, request: AiRequest) -> Result<AiResponse>;
}
```

### 5.2 调度流程

```
用户选择模型
    │
    ▼
前端发送请求 (指定模型 ID)
    │
    ▼
后端接收请求
    │
    ▼
查找端点注册表
    │
    ▼
路由到对应厂商适配器
    │
    ▼
调用厂商官方 API
    │
    ▼
返回结果给前端
```

## 12. 性能优化策略

### 12.1 前端性能

- **虚拟渲染**：只渲染视口内的元素，减少 DOM 节点数
- **LOD 分级**：根据缩放级别切换细节级别，减少渲染负担
- **资源回收**：离开视口的元素主动降级或回收，释放内存
- **懒加载**：按需加载模块和资源，减少首屏加载时间

### 12.2 后端性能

- **连接池**：SQLite 使用 r2d2 连接池，复用数据库连接
- **异步 I/O**：Tokio 多线程异步运行时，高效处理并发请求
- **批量操作**：数据库批量插入/更新，减少事务开销
- **缓存策略**：热点数据缓存，减少重复查询

### 12.3 AI 任务性能

- **并发控制**：限制同时执行的任务数，避免资源耗尽
- **限流策略**：按厂商限制请求频率，避免触发限流
- **重试机制**：失败任务自动重试，提高成功率
- **进度心跳**：实时更新任务进度，避免超时

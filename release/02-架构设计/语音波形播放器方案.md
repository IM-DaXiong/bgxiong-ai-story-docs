## 3. Step 1: Extract Shared Peak Utilities

### File: `ui/src/domain/voice/waveformUtils.ts`

Extract `downsamplePeaks` function and `peaksCache` from `WaveformThumbnail.tsx`. Both the existing `WaveformThumbnail` and the new `WaveformPlayer` import from here, sharing the same cache.

```typescript
// Module-level peak cache with LRU eviction to prevent unbounded growth
const PEAKS_CACHE_MAX = 200;
export const peaksCache = new Map<string, number[]>();

export function setCachedPeaks(key: string, peaks: number[]): void {
  if (peaksCache.size >= PEAKS_CACHE_MAX) {
    const firstKey = peaksCache.keys().next().value;
    if (firstKey !== undefined) peaksCache.delete(firstKey);
  }
  peaksCache.set(key, peaks);
}

/**
 * Downsample raw Float32Array channel data to `targetCount` normalized peak values (0–1).
 * Guard: if channelData has fewer than targetCount samples, blockSize is floored to 1,
 * yielding at most channelData.length bars.
 */
export function downsamplePeaks(channelData: Float32Array, targetCount: number): number[] {
  const blockSize = Math.floor(channelData.length / targetCount) || 1;
  const peaks: number[] = [];
  for (let i = 0; i < targetCount; i++) {
    const start = i * blockSize;
    let max = 0;
    for (let j = start; j < start + blockSize && j < channelData.length; j++) {
      const v = Math.abs(channelData[j]);
      if (v > max) max = v;
    }
    peaks.push(max);
  }
  const peakMax = Math.max(...peaks, 0.001);
  return peaks.map((p) => p / peakMax);
}
```

### 4.3 Audio URL Resolution

Two parallel effects on mount / `audioRelativePath` change:

**Effect A — Peak extraction** (reuses shared `peaksCache` + `downsamplePeaks`):
- Check `peaksCache` → hit: use cached data immediately.
- Miss: fetch audio via `api.mediaSrcFromAppDataRelative()` → `fetch()` → `AudioContext.decodeAudioData()` → `downsamplePeaks()` to **200 bars** → `setCachedPeaks()` → set state.
- AbortController cleanup on unmount or path change.
- If fetch/decode fails: `setPeaksFailed(true)`, log via `logError("voice", "WAVEFORM_PLAYER_PEAKS_FAILED", ...)`.
- Close the `AudioContext` in a `finally` block to avoid exhausting browser limits.

**Effect B — Audio playback URL**:
- Call `api.mediaSrcFromAppDataRelative(rel)`.
- If null returned → `setAudioError(true)`.
- If success → store in `audioSrc` state.

### 4.4 Audio Element Lifecycle

Create a hidden `<audio>` element imperatively via `new Audio()` in a `useEffect`:

```typescript
useEffect(() => {
  const audio = new Audio();
  audio.preload = "auto";
  audioRef.current = audio;

  const onLoadedMetadata = () => {
    setDisplayDuration(audio.duration);
    setAudioError(false);
  };
  const onPlay = () => { setPlaying(true); playingRef.current = true; startRafLoop(); };
  const onPause = () => { setPlaying(false); playingRef.current = false; stopRafLoop(); };
  const onEnded = () => { setPlaying(false); playingRef.current = false; stopRafLoop(); setDisplayTime(0); };
  const onError = () => { setAudioError(true); setPlaying(false); playingRef.current = false; stopRafLoop(); };

  audio.addEventListener("loadedmetadata", onLoadedMetadata);
  audio.addEventListener("play", onPlay);
  audio.addEventListener("pause", onPause);
  audio.addEventListener("ended", onEnded);
  audio.addEventListener("error", onError);

  return () => {
    // Full cleanup: pause, remove src, force load to release media resources
    audio.pause();
    audio.removeAttribute("src");
    audio.load();
    audio.removeEventListener("loadedmetadata", onLoadedMetadata);
    audio.removeEventListener("play", onPlay);
    audio.removeEventListener("pause", onPause);
    audio.removeEventListener("ended", onEnded);
    audio.removeEventListener("error", onError);
    audioRef.current = null;
    stopRafLoop();
  };
}, []); // empty deps — audio element created once, src updated in separate effect
```

A second effect sets the audio source:

```typescript
useEffect(() => {
  const audio = audioRef.current;
  if (!audio || !audioSrc) return;
  audio.src = audioSrc;
  audio.load();
}, [audioSrc]);
```

### 4.5 Progress Tracking via requestAnimationFrame (NOT timeupdate events)

Instead of frequent `timeupdate` events causing excessive React re-renders, use a `requestAnimationFrame` loop that reads `audio.currentTime` and throttles state updates to ~100ms:

```typescript
let lastUpdateMs = 0;
const THROTTLE_MS = 100;

function startRafLoop() {
  const tick = () => {
    const audio = audioRef.current;
    if (!audio || audio.paused) return;
    const now = performance.now();
    if (now - lastUpdateMs >= THROTTLE_MS) {
      setDisplayTime(audio.currentTime);
      lastUpdateMs = now;
    }
    rafRef.current = requestAnimationFrame(tick);
  };
  rafRef.current = requestAnimationFrame(tick);
}

function stopRafLoop() {
  if (rafRef.current) {
    cancelAnimationFrame(rafRef.current);
    rafRef.current = 0;
  }
}
```

`VoiceWorkbench` manages `activePlayingIndex` via `useState`. It provides the context value. `VoiceTaskList` consumes the context and passes `segIndex` + context callbacks to `WaveformPlayer`.

**In `WaveformPlayer`**, accept a `segIndex` prop and context callbacks:

```typescript
// Props addition:
segIndex: number;
onRegisterPlayback: (segIndex: number) => void;
onUnregisterPlayback: (segIndex: number) => void;
activePlayingIndex: number | null;
```

When the user clicks play on segment N:
1. Call `onRegisterPlayback(N)` → VoiceWorkbench sets `activePlayingIndex = N`
2. All other WaveformPlayer instances see `activePlayingIndex !== theirSegIndex` and pause their audio

This is:
- Testable (wrap in a provider in tests)
- Concurrent-mode safe (state is in React tree)
- Survives HMR (state resets with component)
- Explicit data flow (props down, callbacks up)

### 4.7 SVG Rendering

```tsx
const BAR_COUNT = 200;  // matches downsamplePeaks target
const SVG_VIEW_H = 100;

// progressRatio: 0–1
const progressRatio = displayDuration > 0 ? displayTime / displayDuration : 0;
const progressX = progressRatio * BAR_COUNT;

<svg
  ref={svgRef}
  width="100%"
  height={height}
  viewBox={`0 0 ${BAR_COUNT} ${SVG_VIEW_H}`}
  preserveAspectRatio="none"
  style={{ cursor: "pointer", display: "block", borderRadius: 4 }}
  onClick={handleWaveformClick}
>
  {/* Layer 1: All bars — background (unplayed) color */}
  {peaks.map((peak, i) => {
    const barW = (BAR_COUNT / peaks.length) * 0.7;
    const barH = Math.max(1, peak * SVG_VIEW_H);
    const x = (BAR_COUNT / peaks.length) * i + (BAR_COUNT / peaks.length - barW) / 2;
    const y = (SVG_VIEW_H - barH) / 2;
    return (
      <rect key={`bg-${i}`} x={x} y={y} width={barW} height={barH}
            rx={1} fill={color ?? "var(--primary)"} opacity={0.3} />
    );
  })}

  {/* Layer 2: Played portion bars */}
  {progressRatio > 0 && peaks.map((peak, i) => {
    if (i / BAR_COUNT > progressRatio) return null;
    const barW = (BAR_COUNT / peaks.length) * 0.7;
    const barH = Math.max(1, peak * SVG_VIEW_H);
    const x = (BAR_COUNT / peaks.length) * i + (BAR_COUNT / peaks.length - barW) / 2;
    const y = (SVG_VIEW_H - barH) / 2;
    return (
      <rect key={`fg-${i}`} x={x} y={y} width={barW} height={barH}
            rx={1} fill={color ?? "var(--primary)"} opacity={0.9} />
    );
  })}

  {/* Layer 3: Playhead cursor line */}
  {displayDuration > 0 && (
    <line x1={progressX} y1={0} x2={progressX} y2={SVG_VIEW_H}
          stroke="var(--accent, var(--primary))" strokeWidth={2} />
  )}
</svg>
```

Design decisions:
- **200 bars** provides sufficient click granularity for typical 300–600px column widths (~1.5–3px per bar).
- `preserveAspectRatio="none"` stretches the viewBox to fill any container width.
- Bars at integer x-positions with width < 1 create natural gaps when stretched. A 0.7 bar width with 1.0 spacing → 30% gap, visually pleasant.

### 4.8 Click-to-Seek Handler

```typescript
const handleWaveformClick = useCallback((e: React.MouseEvent<SVGSVGElement>) => {
  e.stopPropagation(); // prevent row selection (parent onClick)

  const svg = svgRef.current;
  const audio = audioRef.current;
  if (!svg || !audio || !displayDuration || displayDuration <= 0) return;

  const rect = svg.getBoundingClientRect();
  const ratio = Math.max(0, Math.min(1, (e.clientX - rect.left) / rect.width));
  const targetTime = ratio * displayDuration;

  audio.currentTime = targetTime;
  setDisplayTime(targetTime);

  // If currently paused, start playback (this is "定位播放" — position AND play)
  if (audio.paused) {
    onRegisterPlayback(segIndex);  // pauses all other instances
    audio.play().catch((err) => {
      // Browser autoplay policy may reject; that's OK, position is set
      console.warn("WaveformPlayer: play() rejected by autoplay policy", err);
    });
  }
  // If already playing, the seek is seamless — audio continues from new position
}, [displayDuration, segIndex, onRegisterPlayback]);
```

### 4.10 Time Display

function formatTime(seconds: number): string {
  if (!isFinite(seconds) || seconds < 0) return "0:00";
  const m = Math.floor(seconds / 60);
  const s = Math.floor(seconds % 60);
  return `${m}:${s.toString().padStart(2, "0")}`;
}

<span style={{ fontSize: "var(--textXs)", color: "var(--text3)", textAlign: "right" }}>

### 4.11 Loading, Error, and Non-completed States

| State | Rendering |
|---|---|
| `peaksLoading \|\| audioSrcLoading` | Pulsing placeholder bar at `height`px, `background: var(--surface3)`, `borderRadius: 4` |
| `peaksFailed` | Flat SVG line + "Waveform unavailable" text |
| `audioError` | Flat SVG line + "Audio unavailable" text |
| Completed (normal) | Full interactive SVG waveform |

The `WaveformPlayer` is ONLY rendered for completed segments. Other statuses (`draft`, `queued`, `synthesizing`, `cancelling`, `failed`, `cancelled`) are handled at the call site in `VoiceTaskList` (see Step 3).

### 4.12 Performance Optimization

Wrap `WaveformPlayer` in `React.memo` with a custom comparator that only re-renders when its props or the context's `activePlayingIndex` change. The rAF loop updates DOM refs directly for the playhead line (avoiding React re-renders for every frame):

```typescript
export const WaveformPlayer = React.memo<WaveformPlayerProps>(
  ({ audioRelativePath, durationSec, height = 56, color = "var(--primary)",
     segIndex, onRegisterPlayback, onUnregisterPlayback, activePlayingIndex }) => {
    // ...
  },
  (prev, next) =>
    prev.audioRelativePath === next.audioRelativePath &&
    prev.segIndex === next.segIndex &&
    prev.activePlayingIndex === next.activePlayingIndex &&
    prev.height === next.height
);
```

For the playhead line, use a ref to the `<line>` element and update its `x1`/`x2` attributes directly in the rAF loop (avoiding state update for every frame). Only call `setDisplayTime` at 100ms throttle for the text display.

### 4.13 Edge Cases Covered

| Scenario | Handling |
|---|---|
| Audio file missing from disk | `mediaSrcFromAppDataRelative` returns null → `audioError=true` → "Audio unavailable" |
| Very short audio (< 200 samples) | `downsamplePeaks` floor logic yields `blockSize=1`, producing ≤ sampleCount bars |
| AudioContext.decodeAudioData fails | Caught → `peaksFailed=true` → flat line fallback |
| Autoplay policy blocks `audio.play()` | `.catch(() => {})` — position is set, user can click play button |
| React StrictMode double-mount | `useEffect` cleanup properly pauses + releases audio; second mount creates fresh element |
| User scrolls segment out of view | Unmount cleanup pauses audio; no leak |
| Regeneration produces new audio | `audioRelativePath` change triggers re-fetch of peaks + new audio URL |
| Multiple rapid clicks on waveform | `audio.currentTime = targetTime` is idempotent; last click wins |
| SVG click at extreme edge | `Math.max(0, Math.min(1, ratio))` clamp |
| Duration is Infinity (streaming audio) | `!isFinite(seconds)` guard in `formatTime` → "0:00" |
| Another segment starts playing | Context `activePlayingIndex` changes → this instance pauses |
| Component unmount during rAF loop | Cleanup calls `cancelAnimationFrame` |
| `peaksCache` grows unbounded | LRU eviction at 200 entries |

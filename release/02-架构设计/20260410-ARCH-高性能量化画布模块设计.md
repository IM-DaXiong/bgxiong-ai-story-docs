# 高性能 Canvas 无限画布模块设计方案

## 1. 项目概述

### 1.1 目标
- **性能优先**：支持数千个节点的流畅渲染和交互
- **模块化**：独立可复用的画布组件
- **灵活扩展**：支持多种业务场景（演员、场景、分镜、角色等）

### 1.2 性能指标
- 支持 2000+ 节点流畅渲染
- 交互响应延迟 < 16ms
- 60FPS 渲染性能
- 内存占用降低 60%+

## 3. 性能优化策略

### 3.1 渲染优化
- **对象池**：节点、路径、颜色等对象复用
- **分层渲染**：背景、连线、节点、UI 分层
- **脏矩形更新**：只重绘变化区域
- **LOD 渲染**：低缩放级别简化细节

### 3.2 空间索引优化
- **四叉树**：O(log n) 查询性能
- **空间哈希**：密集区域快速查询
- **边界缓存**：避免重复计算

### 3.3 缓存策略
- **纹理缓存**：节点内容预渲染
- **连接缓存**：连线路径缓存
- **状态缓存**：视口参数缓存

## 4. 实现详情

### 4.1 核心渲染器

```typescript
// core/CanvasRenderer.ts
export class CanvasRenderer<T = unknown> implements CanvasRenderer {
  private canvas: HTMLCanvasElement;
  private ctx: CanvasRenderingContext2D;
  private quadTree: QuadTree<CanvasNode<T>>;
  private textureCache: TextureCache;
  
  constructor(canvas: HTMLCanvasElement) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d')!;
    this.quadTree = new QuadTree();
    this.textureCache = new TextureCache();
  }
  
  render(nodes: CanvasNode<T>[], connections: Connection[] = []): void {
    // 1. 更新空间索引
    this.updateSpatialIndex(nodes);
    
    // 2. 计算视口内可见元素
    const visibleNodes = this.getVisibleNodes();
    const visibleConnections = this.getVisibleConnections(connections);
    
    // 3. 分层渲染
    this.renderBackground();
    this.renderConnections(visibleConnections);
    this.renderNodes(visibleNodes);
    this.renderOverlay();
  }
  
  private renderNodes(nodes: CanvasNode<T>[]): void {
    this.ctx.save();
    this.ctx.transform(
      this.viewport.scale, 0, 0, 
      this.viewport.scale, 
      this.viewport.panX, 
      this.viewport.panY
    );
    
    for (const node of nodes) {
      this.renderSingleNode(node);
    }
    
    this.ctx.restore();
  }
}
```

### 4.2 空间索引系统

```typescript
// spatial/QuadTree.ts
export class QuadTree<T extends { x: number; y: number; width: number; height: number }> {
  private root: QuadTreeNode<T>;
  private capacity: number = 10;
  
  insert(item: T): void {
    if (!this.root) {
      const bounds = { 
        x: -10000, y: -10000, 
        width: 20000, height: 20000 
      };
      this.root = new QuadTreeNode(bounds, this.capacity);
    }
    this.root.insert(item);
  }
  
  query(range: Rectangle): T[] {
    return this.root.query(range, []);
  }
}
```

### 4.3 事件系统

```typescript
// events/EventSystem.ts
export class CanvasEventSystem<T> {
  private renderer: CanvasRenderer<T>;
  private dragManager: DragManager;
  private pointerHandler: PointerHandler;
  
  constructor(renderer: CanvasRenderer<T>) {
    this.renderer = renderer;
    this.dragManager = new DragManager();
    this.pointerHandler = new PointerHandler();
    
    this.setupEventListeners();
  }
  
  private setupEventListeners(): void {
    this.canvas.addEventListener('pointerdown', this.onPointerDown);
    this.canvas.addEventListener('pointermove', this.onPointerMove);
    this.canvas.addEventListener('pointerup', this.onPointerUp);
  }
  
  private onPointerDown = (e: PointerEvent): void => {
    const worldPos = this.screenToWorld(e.clientX, e.clientY);
    const hitNode = this.renderer.getNodeAt(worldPos.x, worldPos.y);
    
    if (hitNode) {
      this.startDrag(hitNode, worldPos);
    } else {
      this.startPan(worldPos);
    }
  }
}
```

## 5. React 组件封装

```typescript
// react/HighPerformanceCanvas.tsx
import { useEffect, useRef, useState } from 'react';

interface HighPerformanceCanvasProps<T> {
  nodes: CanvasNode<T>[];
  connections?: Connection[];
  onNodeMove?: (nodeId: string, x: number, y: number) => void;
  onNodeSelect?: (nodeId: string) => void;
  renderNode?: (node: CanvasNode<T>) => void;
  className?: string;
}

export function HighPerformanceCanvas<T>({
  nodes,
  connections = [],
  onNodeMove,
  onNodeSelect,
  renderNode,
  className
}: HighPerformanceCanvasProps<T>) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const rendererRef = useRef<CanvasRenderer<T> | null>(null);
  const [dimensions, setDimensions] = useState({ width: 0, height: 0 });
  
  useEffect(() => {
    if (!canvasRef.current) return;
    
    rendererRef.current = new CanvasRenderer(canvasRef.current);
    
    return () => {
      rendererRef.current?.destroy();
    };
  }, []);
  
  useEffect(() => {
    if (!rendererRef.current) return;
    
    rendererRef.current.updateNodes(nodes);
    rendererRef.current.render(nodes, connections);
  }, [nodes, connections]);
  
  return (
    <canvas
      ref={canvasRef}
      className={className}
      width={dimensions.width}
      height={dimensions.height}
    />
  );
}
```

## 6. 使用示例

### 6.1 基础使用
```typescript
import { HighPerformanceCanvas, CanvasNode } from 'high-performance-canvas';

function MyCanvas() {
  const [nodes, setNodes] = useState<CanvasNode<MyData>[]>([]);
  
  return (
    <HighPerformanceCanvas
      nodes={nodes}
      onNodeMove={(id, x, y) => {
        setNodes(prev => prev.map(n => 
          n.id === id ? { ...n, x, y } : n

      }}
      renderNode={node => (
        <div style={{ backgroundColor: node.data.color }}>
          {node.data.label}

  );
}
```

## 7. 性能监控

```typescript
// utils/perf.ts
export class PerformanceMonitor {
  static measureRenderTime(renderFn: () => void): number {
    const start = performance.now();
    renderFn();
    return performance.now() - start;
  }
  
  static trackMemoryUsage(): MemoryInfo {
    return performance.memory || { used: 0, total: 0 };
  }
}
```

## 8. 迁移策略

### 8.1 渐进式迁移
1. **第一阶段**：开发 Canvas 版本，保持原有 DOM 版本
2. **第二阶段**：添加配置开关，可选择使用 Canvas 或 DOM

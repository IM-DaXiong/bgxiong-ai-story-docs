## 4. 运行时与外部程序（不在 Cargo / npm 清单内）

以下是产品会调用或按需安装的外部运行时，版本以运行时清单与用户环境为准：

- FFmpeg / ffprobe（媒体探测、转码、合成）
- 本地文本推理服务（如 llama-server）
- Whisper 语音识别命令行运行时（进程内绑定为可选特性）
- Python sidecar（部分本地语音或音频能力）
- ComfyUI（本地工作流）

具体下载、校验与安装步骤见开发指南中的运行时与模型清单类文档；涉及账号令牌的步骤只保留占位符。

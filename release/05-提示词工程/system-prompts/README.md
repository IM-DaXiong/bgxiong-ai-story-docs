## 学习价值

### 提示词设计模式
- 角色定义（Role Setting）
- 任务描述（Task Description）
- 约束条件（Constraints）
- 输出格式（Output Format）
- 示例引导（Few-shot Examples）

### 安全研究
- 提示词注入防护
- 越狱攻击防御
- 敏感信息保护

### 产品设计
- AI 助手构建
- 多轮对话设计
- 工具调用编排

## 使用建议

1. **学习为主**：这些提示词主要用于学习和研究，不建议直接复制用于商业用途
2. **注意协议**：部分仓库有 GPL/AGPL 协议，使用时需遵守
3. **持续更新**：建议定期访问获取最新版本
4. **结合实践**：参考这些模式设计自己的提示词

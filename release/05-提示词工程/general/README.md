# 通用提示词库

> 覆盖写作、编程、商业、创意、教育等多场景的综合提示词集合。

## 推荐仓库

### ⭐ f/awesome-chatgpt-prompts（163k Stars）

- **地址**：https://github.com/f/awesome-chatgpt-prompts
- **语言**：英文
- **格式**：CSV, Markdown, HuggingFace Dataset
- **特点**：
  - 全球最大开源提示词库
  - 原为 ChatGPT 设计，现支持 Claude、Gemini、Llama、Mistral
  - 包含思维链推理、少样本学习、AI 代理等进阶内容
  - 交互式学习书籍
- **适用场景**：几乎所有场景

### ⭐ rockbenben/ChatGPT-Shortcut（8.5k Stars）

- **地址**：https://github.com/rockbenben/ChatGPT-Shortcut
- **语言**：18 种语言
- **特点**：
  - AI 提示词管理平台（AiShort）
  - 浏览器扩展支持
  - 社区投票、拖拽收藏、自定义创建
  - 在线版：aishort.top
- **适用场景**：写作、编程、办公、设计、营销

### yokoffing/ChatGPT-Prompts（897 Stars）

- **地址**：https://github.com/yokoffing/ChatGPT-Prompts
- **语言**：英文
- **格式**：Markdown
- **特点**：
  - 100+ 精选提示词
  - CC0-1.0 开源协议
  - 覆盖摘要、写作、数据分析、营销、故事创作、产品设计
- **适用场景**：日常办公、内容创作

## 使用建议

1. 访问仓库主页查看完整列表
2. 下载 CSV/JSON 文件方便本地使用
3. 根据场景选择合适的提示词模板
4. 结合 `prompt-engineering/` 目录的指南优化提示词

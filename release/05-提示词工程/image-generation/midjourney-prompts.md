## 高级技巧

### 1. 权重调整
使用 `::` 和数字来调整提示词的权重：
```
dragon::2 castle::1  // dragon 的权重是 castle 的两倍
```

### 2. 负面提示词
使用 `--no` 来排除不需要的元素：
```
a beautiful landscape --no buildings, people
```

### 3. 风格参考
使用 `--style` 来指定风格：
```
a portrait --style raw
```

### 4. 版本选择
使用 `--v` 来指定 Midjourney 版本：
```
a fantasy scene --v 6
```

### 5. 宽高比
使用 `--ar` 来指定宽高比：
```
a landscape --ar 16:9
```

### 6. 混乱程度
使用 `--chaos` 来控制变化程度：
```
an abstract art --chaos 50
```

### 7. 风格化程度
使用 `--stylize` 来控制风格化程度：
```
a creative artwork --stylize 1000
```

## 常见问题

### Q: 如何提高图像质量？
A: 添加质量标签如 `masterpiece, best quality, highly detailed, 8k`

### Q: 如何获得特定风格？
A: 使用明确的风格标签，如 `oil painting, watercolor, anime`

### Q: 如何控制光线？
A: 使用光线标签如 `golden hour, dramatic lighting, soft lighting`

### Q: 如何调整构图？
A: 使用构图标签如 `close-up, wide angle, rule of thirds`

### Q: 如何获得一致的风格？
A: 使用相同的风格标签组合，保持一致性

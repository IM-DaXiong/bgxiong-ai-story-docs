## 图像生成提示词结构

### 基础结构
```
[主体描述] + [风格修饰] + [技术参数] + [质量标签]
```

### 示例
```
A cute cat sitting on a windowsill, 
watercolor painting style, 
soft lighting, 
8k, highly detailed, masterpiece
```

### 常用分类

#### 风格类
- 艺术风格：油画、水彩、素描、漫画、像素艺术
- 摄影风格：人像、风景、微距、长曝光、HDR
- 特殊风格：赛博朋克、蒸汽朋克、吉卜力、迪士尼

#### 质量类
- 分辨率：4k, 8k, high resolution
- 细节：highly detailed, intricate details, sharp focus
- 品质：masterpiece, best quality, professional

#### 光线类
- 自然光：natural lighting, sunlight, golden hour
- 人工光：studio lighting, neon lights, dramatic lighting
- 特殊光：volumetric lighting, rim light, backlit

#### 构图类
- 角度：close-up, wide angle, bird's eye view, low angle
- 构图：rule of thirds, symmetrical, centered
- 景深：shallow depth of field, bokeh, deep focus

## 使用建议

1. **模型匹配**：选择与你使用的模型匹配的提示词库
2. **风格参考**：浏览示例图片找到喜欢的风格
3. **参数调整**：根据效果调整权重和参数
4. **组合创新**：将不同提示词元素组合创造新风格

## 中文提示词特点

### 语言特性
- 中文语序与英文不同，需要调整结构
- 成语、俗语可以增加表达力
- 文言文风格可用于特定场景

### 常用表达

#### 角色设定
```
你是一位资深的中文写作专家，擅长...
```

#### 任务描述
```
请帮我完成以下任务：
1. ...
2. ...
3. ...
```

#### 输出要求
```
要求：
- 使用中文
- 保持专业
- 字数控制在 XXX 字以内
```

### 中文特有技巧

#### 使用成语
```
请用四个成语描述这个场景。
```

#### 文言文风格
```
请以文言文风格改写以下内容。
```

#### 地域特色
```
请用四川话/东北话/粤语风格改写。
```

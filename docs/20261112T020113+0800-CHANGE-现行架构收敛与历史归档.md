## 源码核实结论（公开可讨论的部分）

- 现行创作主线是 **故事 → 剧集 → 片段**。桌面主窗口将「片段」标签装配为 `ClipWorkflowTab`（`clip_workflow`）。
- 主导航故事分组的日常入口是故事、角色、故事道具、剧集、片段。历史标签 `scenes`（场次）、`storyboard`（故事板）、`segments`（旧片段画布入口）会规范化到现行片段工作台。
- 创作工具发布目录含故事创建与片段工作台现行能力（如剧集生成、片段生成与片段工作台读写 / 变更准备等）；故事板交接与生成、场次生成、旧 Clips 变更类能力不在现行发布目录中。
- 「场景资产」（`sceneAssets` / 视觉资产）仍是现行能力，与已退役的故事层级「场次」不是同一概念。
- 源码树中仍可能保留故事板、场次、旧 Clips 等历史实现；退役指发布面与日常入口，禁止整目录删除，也不把存量代码或历史文档当成现行设计。
- 源工作区另有与助手模块相关的未提交改动，**未**作为上述结论依据；本整理未修改源仓库。

- 历史目录说明和每篇历史文档顶部标明：「历史演进产物，不代表当前设计，不作为当前实现或开发依据。」并记录原路径；文件名中的日期或版本只作为原标识抄录，不编造时间。

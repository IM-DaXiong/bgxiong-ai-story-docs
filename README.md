## 关于源项目

比格熊数字导演工作站是一套 AI 驱动的桌面端影视创作平台：

- **技术栈**：Tauri 2（Rust）+ React 19 + TypeScript 5.9 + SQLite
- **代码规模**：约 198 万行有效代码（2026-11-12 口径）
- **核心理念**：本地优先、数据主权、直连 API、不降级不兜底
- **现行创作主线**：故事 → 剧集 → 片段（片段工作台为现行 `clip_workflow`；故事板、场次编排与旧 Clips 已退出日常创作入口）
